# pyqt5-note-app

Modern ve kullanıcı dostu bir masaüstü not alma uygulaması.  
PyQt5 ile geliştirilmiştir ve notlarınızı JSON formatında kaydeder.  
Basit arayüzü, hızlı arama özelliği ve CSV dışa aktarma fonksiyonu ile pratik bir kişisel not yöneticisidir.


## Özellikler

- Not oluşturma, düzenleme ve silme  
- Otomatik tarih (oluşturulma & güncellenme) kaydı  
- Başlığa göre arama  
- JSON dosyasında güvenli veri saklama  
- Notları CSV formatında dışa aktarma  
- Kaydedilmemiş değişiklik uyarısı  
- Temaya uygun modern tasarım (Dark / Light desteği)
